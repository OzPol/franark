# ADR-0003: Separate findings, acceptance, and execution authority

Status: accepted. Template version: 0.1.0.

## Context

Agents should reduce coordination work while keeping conclusions traceable and
actions consistent with the project's authority.

## Decision

FRAN applies declared priority rules to source evidence. Reviewer acceptance
checks a deliverable. A tool/action policy separately governs any external
execution. The pilot produces drafts and checks without external business tools.

## Consequences

Agreement among agents does not substitute for source support or tests. Future
execution adapters need exact-action records, resource-scoped permissions,
idempotency, and outcome verification.
