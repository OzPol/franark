# Franark documentation

Franark organizes a configurable agent team around tasks, evidence, review,
and recorded outcomes. The local pilot accepts notes, runs a selected workflow,
and prepares an action list and management draft.

Start with the launch tutorial, then use the task-specific how-to guides.
Reference pages describe configuration and interfaces; explanations describe
the decisions behind the architecture.
