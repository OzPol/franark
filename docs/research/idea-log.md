# History of ideas and implementation

This ledger records origins and decisions; it does not backdate experiments or
claim that earlier assistant suggestions were implemented or approved.

## 2026-11-19 — Oz's simulator and system direction

- Input artifact: `cognitive_compression_multi_agent_simulator.html`.
- Oz proposed using six information mechanisms as a foundation for FranArk and
  potentially for SFC's agents.
- Review found isolated demonstrations, hand-written activation thresholds,
  synthetic system metrics and a placeholder semantic audit. Some local sequence
  and residual calculations were real; the complete pipeline was not executed.
- Oz prioritized building and understanding the system and recording measurements
  before looking for research improvements. Established methods are acceptable.
- Additional requirements: an employee resource/application hub; tablet forms and
  signatures; linked documents and structured records; reviewable case-note drafts;
  careful error notifications; supported destination exports; source-linked FAQs;
  Microsoft identity; personal development and later SFC deployment configurations.

## 2026-11-19 — first executable method suite

- Extended `OzPol/franark`'s existing Python contracts instead of replacing its
  agent/workflow design. Work tracked under `CAP-001` (local scope ID).
- Added callable BM25 selection, exact state deltas, DEFLATE storage encoding,
  field projection, BM25+MMR sentence extraction and a change-boundary timeline.
- Each function identifies its source method, adaptation and limitations.
- Added bounded function calling through existing role/instance/project tool
  grants. External business actions remain unconnected.
- Added a local capabilities lab, content-free measurement history and explicit
  reproduction-bundle download. Bundles contain input/output and must not be
  committed when they contain operational data.
- No adaptive policy, learning loop, biological model, eCIRTS importer, Azure
  database adapter, production SSO, signature provider or form workflow has been
  implemented by this change.
